# TinyPlayer 产品文档

本文面向使用者、测试者和产品维护者，说明 TinyPlayer 是什么、能做什么、每项功能的行为规则，以及已知限制和后续方向。技术实现见 [architecture.md](architecture.md)。

## 1. 产品定位

TinyPlayer 是一款 Windows 和 macOS 上的**本地视频播放器 + 个人媒体库**。

- **快**：双击视频后立即开始播放（冷启动约 0.5 秒），大文件夹的扫描在后台完成，不拖慢起播。
- **稳**：播放内核是成熟的 libmpv，格式覆盖面和解码质量与 mpv 相同。
- **占用小**：安装包约 30–50 MB；空闲时 CPU 为 0，播放 1440P 约 170 MB 内存。
- **管得住**：媒体库、标签、收藏、续播、播放次数、重复检查，适合本地收藏较多的人。

目标用户：在电脑上看本地视频（课程、影视、录像、VR 视频）的个人用户，尤其是文件多、需要续播和整理的人。

不做的事：在线视频平台、流媒体订阅、云同步、视频编辑。

### 设计原则

1. **播放优先**：任何后台工作（扫描、缩略图、重复检查、跨盘复制）在播放时暂停，回到媒体库后继续。
2. **不打扰**：播放中不弹更新对话框；控件在鼠标离开后自动收起；无边框模式只留画面。
3. **数据在本地**：所有记录存在本机 SQLite；唯一的网络请求是每天最多一次的更新检查（可关闭，不发送使用数据）。
4. **不删用户文件**：媒体库里“移除”只是不再显示；重复检查默认全部保留，手动确认后才移到废纸篓；跨盘移动校验成功后才删除原文件。
5. **规则可预期**：续播、计数、保存时机都有明确阈值（见 [§6 播放记录](#6-播放记录)），避免误覆盖进度。

## 2. 安装与平台

| 平台 | 安装包 | 说明 |
|---|---|---|
| Windows 10/11 x64 | `TinyPlayer-<版本>-windows-x64-setup.exe` | 安装版，无需管理员权限，注册文件关联和右键菜单，支持应用内更新 |
| Windows 10/11 x64 | `TinyPlayer-<版本>-windows-x64.zip` | 便携版，解压即用，不写注册表，不支持应用内更新 |
| macOS 15+（Apple 芯片） | `TinyPlayer-<版本>-macos-arm64.dmg` | 拖到“应用程序”安装，支持应用内更新 |

下载地址：[GitHub Releases](https://github.com/calabli/TinyPlayer/releases)。安装包没有付费签名，首次打开时 Windows SmartScreen 或 macOS 可能拦截：macOS 上先打开一次，再到“系统设置 → 隐私与安全性”点“仍要打开”。

数据目录：

| 平台 | 位置 |
|---|---|
| Windows | `%APPDATA%\TinyPlayer\` |
| macOS | `~/Library/Application Support/TinyPlayer/` |

其中 `tinyplayer.db` 是数据库（播放记录、媒体库、设置），`thumbs/` 是缩略图。设置环境变量 `TINYPLAYER_DATA_DIR` 可换到别的目录（测试或便携使用）。

## 3. 界面结构

- **播放页**：启动后默认进入。没有视频时显示空状态（打开文件、最近播放、进入媒体库）；播放时画面铺满窗口，底部是控制栏，右侧是可收起的播放列表和章节/书签侧栏。顶部标题右侧有收藏按钮（媒体库中的视频）和文件夹按钮，后者在访达 / 资源管理器中打开视频所在的文件夹并选中它（Ctrl/⌘ + E，网络地址不显示）。
- **媒体库**：没有播放时可进入，包括首页（卡片网格）、文件夹视图和管理页。
- **快捷设置面板**：播放时点控制栏的齿轮，在右下角弹出，调整当前视频的字幕、声音、画面。
- **设置窗口**：Ctrl/⌘ + , 打开，保存长期偏好。

## 5. 功能说明

### 5.1 播放列表

- 打开单个文件时，自动把同一文件夹的其他媒体文件按**自然顺序**加入列表（「第2讲」排在「第10讲」前面），可在 设置 → 播放 中关闭。**先立即播放，同目录扫描在后台线程进行**，扫完再并入列表，不影响起播速度（实测 2 万个文件的文件夹也能立即开始播放）；扫描期间如果手动改了列表或打开了别的文件，结果会被丢弃
- 拖入或打开文件夹 = 播放整个文件夹
- 播完后：播下一个 / 列表循环 / 单个循环；随机播放保证每个文件播一次后才重复
- 侧栏**浮在画面上方，不会缩放视频**。打开方式：暂停后点画面右侧的 ‹，或控制栏的列表按钮，或按 L
- 侧栏内：点击播放、拖动排序、悬停出现 × 移除；鼠标在侧栏上时滚轮滚动列表（不调音量）

列表由程序自己管理（不用 mpv 内置播放列表），以便控制循环、随机、排序等规则。

### 5.2 章节和书签

- **章节**：有章节的文件在进度条上显示刻度，悬停时显示章节名。上一章在章节开始 3 秒内跳到前一章，之后回到本章开头
- **书签**：Ctrl/⌘+B 在当前位置添加，进度条上用圆点标出，1 秒内不重复添加。书签和播放次数一样，清除播放记录时保留；隐私模式下不保存；只支持本地文件，文件大小变了就不再匹配
- 按 G 或点侧栏的 MARKS 标签，可按时间查看章节和书签，点击跳转，悬停书签出现 × 删除

### 5.3 进度条预览

鼠标悬停或拖动进度条时显示该位置的画面。后台用一个无窗口的 libmpv 实例取最近的关键帧，只处理最新的请求，每个文件最多缓存 24 张，空闲 20 秒后释放该实例。网络地址不生成预览。

设好 A-B 循环后，进度条上会用黄色标出循环区间；打开新文件时自动清除。

### 5.4 快捷设置面板

播放时点控制栏的设置按钮，在画面右下角弹出：

| 页 | 内容 |
|---|---|
| 字幕 | 字幕轨道切换（含关闭）、加载字幕文件、字幕大小、位置、字幕延迟 ±0.5 秒 |
| 字幕样式 | 第二字幕（双字幕）、字体、颜色、描边、阴影、覆盖 ASS 样式 |
| 声音 | 音轨切换、声道（立体声 / 左 / 右 / 混合）、音频延迟 ±0.1 秒、音量 ±5% / 静音、音量标准化 |
| 均衡器 | 10 段（31 Hz ~ 16 kHz，±12 dB），预设：关闭 / 低音 / 人声 / 高音 / 影院 |
| 画面 | 画面比例（原始 / 4:3 / 16:9 / 2.35:1 / 铺满窗口 / 21:9）、向左/向右旋转、水平镜像 / 垂直翻转、硬件加速、画质增强（去色带 + 更锐利的缩放，GPU 占用更高）、重置 |
| 画面增强 | 裁剪（去黑边 / 16:9 / 4:3 / 2.35:1 / 1:1）、缩放、HDR 色调映射、插帧 |
| 色彩 | 亮度、对比度、饱和度、伽马、色调（-100 ~ +100，靠近 0 时自动吸附）、重置 |
| 定时 | 睡眠定时：15 / 30 / 45 / 60 / 90 分钟后自动暂停，或播完当前视频后停下、不接着播下一个；剩 1 分钟时会提示。多屏时到点暂停所有画面。只在本次运行有效 |

画面比例、硬件加速、画质增强、字幕大小、位置和样式、音量标准化、均衡器会保存；HDR 色调映射、插帧也会保存；第二字幕和声道只在本次运行有效，裁剪和缩放只对当前文件有效；旋转、翻转、色彩和延迟只在本次运行有效。翻转由 CPU 上的视频滤镜完成，开启时硬件解码自动切到回传模式（`auto-copy-safe`），占用略高，关闭后恢复。点面板外或按 Esc 关闭，「更多设置」打开完整设置窗口（也可按 Ctrl/⌘+,）。

### 5.5 画面增强

- **去黑边**：用一个无窗口的 libmpv 实例取视频 20% 处的约 1 秒画面检测黑边，不影响正在播放的画面；所取片段全黑或黑边不足 2% 时不裁剪
- **HDR 色调映射**：把 HDR 画面映射到显示器范围，非 HDR 视频不起作用
- **插帧**：混合相邻帧让运动更平滑，默认关闭。开启后界面按屏幕刷新率持续重绘，CPU/GPU 占用更高，也更费电。render API 不提供刷新率，所以程序每 2 秒读取 mpv 的测量值并吸附到最近的标准刷新率，窗口移到其他显示器后会自动跟上

### 5.6 音效

音量标准化自动拉近响亮和安静段落的差距，用的是 FFmpeg 的 `dynaudnorm`（RMS 模式）。它需要向后看约 1 秒音频，所以只在开启时有这部分处理延迟。均衡器提升某一段时，会先按最大提升量降低整体音量，防止削波，所以开启后整体可能变轻。

### 5.7 多屏同播

播放时点顶栏右侧的 **多屏** 开关，同一窗口最多同时播放 4 个视频：

- **都出声，互不影响**：每个画面是独立的播放器，有自己的播放/暂停、进度、音量（新开的画面默认 50%）和播放记录
- **点画面播放/暂停**；**双击、按 F 或点控制条右端的充满按钮，让这个视频充满自己的格子**：放大画面、裁掉上下或左右的黑边，格子大小和其他画面都不变；再双击、按 Esc 或再点一次按钮恢复完整画面。标题栏的放大按钮则只在窗口内放大。点空白格从「打开文件…」或播放列表添加视频，也可以把文件直接拖到某个格子上：拖动时会高亮将要替换的画面，松开就在这一格播放，原来的视频被替换。每个画面标题栏右端的 **×** 关闭这个视频，画面回到「添加视频」的初始状态，布局不变；空白格上的 × 才会移除这一格
- **灵活布局**：预设 单屏 / 左右 / 上下 / 四宫格 / 一大三小 / 画中画；每个画面标题栏的按钮可再左右或上下分屏、变成画中画小窗（可拖动、拖右下角缩放）或放回布局；拖动分隔线调比例，拖动标题和别的画面交换位置
- **隐藏进度条**：每个画面的控制条和标题栏只在鼠标移到该画面上时出现，鼠标停住约 2 秒后自动隐藏（暂停时保留），播放中的画面上鼠标指针也一起隐藏；顶栏的 **进度条** 开关关掉后，控制条只在鼠标移到该画面底部时出现
- **退出多屏**：同时有多个视频在播放时不能退出，需要先用 × 关掉其他画面；只剩一个视频时关掉 **多屏** 开关，它会转成普通的单视频播放，从当前进度接着放
- **联动**：打开后播放/暂停、跳转、倍速同步到所有画面，音量仍各自独立
- **只听选中**：打开顶栏的这个开关后，只有选中的画面（蓝色描边）出声，其他画面自动静音；点别的画面的标题栏或控制条、或按 Tab 换选中，声音跟着换。期间仍可用静音按钮单独开关某个画面的声音；关掉开关后所有画面恢复出声
- 多屏时键盘作用于当前选中的画面（蓝色描边），Tab 切换，Z 放大选中画面；空格、←/→、↑/↓、M、, / .（逐帧）与单屏相同。底部大控制栏和侧栏隐藏，每个画面有自己的迷你控制条
- 实测 4 路 1440P（硬件解码）同时播放：CPU 约占单核 12%，内存约 590 MB

### 5.8 媒体库

没有播放时显示媒体库首页。点「+ 添加文件夹」后，后台会递归扫描文件夹，用一个无窗口的 libmpv 实例（`vo=image`）读取时长、分辨率，并截取 10% 处的画面作为缩略图（480 像素宽，约 0.2 秒一个）。每次启动会重新扫描，以发现新增或修改过的文件。

- 左侧导航：全部 / 继续观看 / 最近添加（7 天内）、标签筛选（可多选，同时满足）、按文件夹筛选；悬停文件夹出现 × 可从媒体库移除（不删除文件）
- 启动页：打开程序先进入播放页，点「进入媒体库」或播放页的「媒体库」进入媒体库
- 媒体库密码：在 设置 → 媒体库 开启后，进入媒体库需要输入密码，启动后要重新验证，也可以点「锁定」立刻锁上。只保存加盐的哈希值，用于挡住界面入口，不会加密视频或缩略图。忘记密码时只能清除媒体库并取消密码
- 清除媒体库：在 设置 → 媒体库 一键移除全部文件夹、标签、收藏归类和集合，不删除视频文件，也不清除播放记录
- 播放优先：打开视频期间，扫描、缩略图、可能重复比较和跨磁盘复制都会暂停，回到媒体库后自动继续
- 大媒体库：底部进度条显示扫描和处理进度，以及预计剩余时间。缩略图由最多 3 个后台进程生成，中途退出后下次继续。2 万个视频时界面仍保持流畅
- 管理页：点顶部的「管理」进入。可以把多个文件夹组成集合；列表显示缩略图、时长、大小和修改日期，点列标题排序；搜索同时匹配文件夹和视频；单击视频播放，用勾选框或 Ctrl/⌘ + 点击多选
- 重命名和批量操作：右键视频可以重命名，进度、收藏和标签都保留；多选后可以一起加标签或加入收藏
- 外接硬盘：硬盘拔掉后显示为未连接并保留记录，重新接上后自动恢复
- 剪切：把视频或整个文件夹移到媒体库内的其他位置，也可以在选择目标时新建文件夹。同名时自动改名并保留两者，进度、播放次数、标签、书签和 VR 设置都保留。跨磁盘时先复制并校验，成功后才删除原文件，中途取消时原文件不变。完成后可以撤销
- 可能重复：可以只检查某个文件夹及其子文件夹（在文件夹页或左侧文件夹列表右键文件夹，或在管理页进入文件夹后点按钮、右键文件夹）。按时长、大小和名称模糊比较，不读取文件内容，可选择比较条件和严格程度。结果只是建议，默认全部保留，手动标记后才移到系统废纸篓；点「不是重复」后不再提示这组
- 搜索：同时匹配标题、标签和路径，多个关键词用空格分隔；Ctrl/⌘+K 聚焦，Esc 清空
- 排序：最近添加 / 最近播放 / 名称（自然排序）/ 时长
- 卡片：缩略图、分辨率角标、时长、观看进度、播放次数、标签；点「+ 标签」添加，右键菜单可移除标签、在资源管理器/访达中显示、从媒体库移除
- 播放界面左上角「‹ 媒体库」返回首页
- **收藏夹**：悬停卡片点右上角星标，勾选要放入的收藏夹（可多个，可在弹窗里直接新建）；左侧 COLLECTIONS 点「+」新建，右键删除。播放时标题旁的星标或 Ctrl/⌘+D 快速收藏/取消（放入第一个收藏夹）。只有媒体库里的视频能收藏
- **最常播放**：按播放次数排名，前三名高亮；任意视图也可按「播放次数」排序
- **文件夹视图**：顶栏切换「媒体库 / 文件夹」，面包屑导航、↑ 返回上级；子文件夹显示为四宫格封面卡片（视频数、总时长、已看完数量），「播放全部」或右键文件夹卡片按自然顺序播放其中所有视频

搜索用 `LIKE` 而不是 FTS5：SQLite 的全文分词不切分中文，「王朝」搜不到「大明王朝」。几千条记录在内存里过滤也只需不到 1 毫秒。

缩略图保存在数据目录的 `thumbs/` 下。

### 5.9 窗口与桌面集成

- **记住窗口**：退出时保存窗口位置、大小和是否最大化，下次启动恢复（全屏状态不保存）。可在 设置 → 界面 关闭“记住窗口布局”，之后每次都在屏幕中间以默认的 854×480 小窗口打开
- **单实例**：TinyPlayer 已在运行时，再打开视频（双击、拖到 exe 上、命令行）会交给已有窗口播放并把它切到前台，不会再开一个窗口。实现方式是本机回环端口通信，端口由数据目录推算，所以设置了不同 `TINYPLAYER_DATA_DIR` 的实例（测试、便携版）互不干扰
- **文件关联**（Windows 安装版）：所有支持的格式都能在“打开方式”和系统的默认应用设置里选 TinyPlayer，右键菜单还有“用 TinyPlayer 播放”（Windows 11 在“显示更多选项”里）。Windows 不允许程序自己设为默认播放器，要设默认请在“打开方式”里勾选“始终”。卸载时一并清除。便携版 zip 不做这些注册
- **打开方式**（macOS）：可以从访达双击或用“打开方式”选择 TinyPlayer，TinyPlayer 已在运行时交给已有窗口
- **图标**：`python scripts/make-icon.py` 只用标准库生成 `assets/` 下的图标；Windows 构建时嵌入 exe，窗口左上角也使用它；macOS 打包脚本会转成 `.icns`
- **媒体键**：键盘媒体键、macOS 控制中心、Windows 音量浮层可以播放、暂停、切换上一个/下一个，并显示当前标题和进度
- **阻止休眠**：播放视频时屏幕不熄灭，只播音频时系统不休眠但屏幕可以熄灭；暂停或播完后恢复
- **按设备记音量**：耳机、扬声器等每个输出设备各记一个音量，切换系统输出设备后自动换成该设备的音量。第一次用的设备沿用当前音量。可以在“设置 → 声音”关闭，或查看、修改和删除各设备的音量
- **无边框播放**：播放或暂停时默认只显示画面。鼠标移到顶部显示标题和窗口按钮（最小化、关闭），移到底部显示播放控件，移到右侧中间可打开播放列表。离开相应区域后控件收起。按 H 或在快捷面板的“画面增强”里开关，设置会保存。拖动画面可移动窗口；回到媒体库或全屏时恢复标题栏
- **VR 全景**：在普通屏幕上看 180° 和 360° 等距柱状投影视频，拖动画面转视角，滚轮或 = / - 缩放，0 回正。左右、上下格式的 3D 视频只显示左眼画面。文件名带 `360`、`180`、`VR`、`SBS`、`TB` 等标记且画面比例相符时自动开启，也可以按 V 或在快捷面板的“VR 全景”里手动设置，每个文件记住各自的选择（隐私模式下不保存）。全景模式下不显示字幕，画质增强和插帧暂时停用，退出后恢复；截图保存的是完整全景画面；不支持 VR 头显和鱼眼格式
- **画中画**：无边框小窗置顶在屏幕右下角，拖动画面可移动窗口，拖动边缘或四角可按视频比例缩放，再次打开时沿用上次大小；退出后回到原位置和大小；全屏时需先退出全屏。窗口置顶和画中画只在本次运行有效
- **字幕避让**：控制栏显示时字幕自动上移到进度条上方，隐藏后回到底部

### 5.10 主题、语言、多开与更新

设置 → 界面 可以切换主题和语言，立即生效并保存：

- **主题**：深色、浅色、跟随系统。只影响媒体库、空状态页和设置窗口；控制栏、侧栏和快捷面板压在画面上，始终是深色
- **多开窗口**（默认关闭）：打开后，已经有 TinyPlayer 在运行时再打开视频（双击文件、拖到图标上、命令行）会另开一个窗口，而不是把文件交给正在运行的窗口；Ctrl/⌘+N 新开一个空窗口。每个窗口是独立的进程，各有自己的播放、播放列表、多画面、隐私模式和睡眠定时，一个窗口卡住或关闭不影响其他窗口。它们共用媒体库、播放记录和设置：设置里谁改了哪一项就只写哪一项，不会互相覆盖，但别的窗口要重新打开才会读到新设置。后开的窗口不再重复做启动时的清理、更新检查和媒体库扫描，位置会错开一点，关闭它们也不会清除播放记录（“退出时清除”只在第一个窗口退出时执行）。macOS 上从访达打开文件时，正在播放的窗口会保留，另开新窗口；没在播放的空窗口则直接用它。多个窗口同时开着时，键盘媒体键和控制中心只会控制最近一个播放的窗口
- **应用内更新**：启动后最多每天访问一次 GitHub 检查新版本。版本号相同时还会比较构建 commit，不同就提示更新；版本号高于最新发布版的构建不提示，本地编译的版本只比版本号。在程序里下载并安装，不用打开浏览器。默认在后台下载，完成后询问“立即重启 / 稍后”，选稍后就在退出时安装；关闭自动下载后，发现新版本时询问“立即更新 / 稍后提醒 / 跳过此版本”，下载可以取消。播放视频时不弹窗。下载的文件要与发布的 `SHA256SUMS` 一致才会安装，替换失败时恢复旧版。可在 设置 → 界面 关闭或手动检查，隐私模式下不自动检查。安装版才支持，便携版 zip 和从 DMG 直接运行时只提示。需要系统自带的 `curl`（macOS、Windows 10/11 都有）
- **语言**：中文（默认）、English。播放时的部分英文提示（如 `VOLUME 60%`）两种语言下相同。更新对话框按所选语言显示更新内容

## 6. 播放记录

数据存在 SQLite：Windows 为 `%APPDATA%\TinyPlayer\tinyplayer.db`，macOS 为 `~/Library/Application Support/TinyPlayer/tinyplayer.db`。
开发测试时可以设置环境变量 `TINYPLAYER_DATA_DIR` 指向别的目录，避免写入真实记录。

| 规则 | 说明 |
|---|---|
| 文件识别 | 路径 + 文件大小；同名但内容换了的文件不会继承旧进度 |
| 何时保存 | 每播放 10 秒、暂停、播完、切换文件、正常退出时 |
| 防误删 | 实际观看不到 5 秒不写入，打开后马上关闭不会覆盖上次的进度 |
| 播放次数 | 实际观看 ≥ 30 秒或时长的 10%（取较小值）才 +1；30 分钟内重复打开只算一次；按真实时间计，倍速不影响 |
| 退出时清除 | 只清空进度和最近播放，**播放次数保留**；启动时也会再清一次，防止上次崩溃没清掉 |
| 隐私模式 | Ctrl/⌘+Shift+P 或在设置中开启。本次运行不写入播放记录（包括播放次数），隐藏继续观看、最近播放和观看进度，系统媒体控制只显示 TinyPlayer，不显示片名；顶部显示 PRIVATE，重启后自动关闭 |

已知限制：程序被强制结束时，最多丢失最近 10 秒的进度。

设置窗口（Ctrl/⌘ + ,）的各页及其中的项目。除特别说明外，修改立即生效并保存。

## 8. 性能指标

在 16 核 / NVIDIA 显卡的 Windows 机器上，用 release 版实测（1440P H.264，NVDEC 硬解）：

| 场景 | CPU | 内存（任务管理器「内存」列） |
|---|---|---|
| 启动到窗口出现 | — | 约 0.47 秒 |
| 空闲（空状态页） | 0% | 约 94 MB |
| 播放 1440P | 单核约 2–16%（整机 1% 以内） | 约 173 MB |
| 暂停 / 播放结束 | 0% | 约 138 MB |
| 400 个视频的媒体库，从头滚到尾 | — | 109 → 112 MB |

做过的优化：只在有新帧或输入时重绘；单实例先抢端口再连接（冷启动少约 300 ms）；中文字体用内存映射加载（约 −19 MB）；本地文件不强制预读缓存（`cache=auto`）；后台生成缩略图的 mpv 实例用完即释放（大媒体库约 −130 MB）；缩略图纹理最多保留 160 张，滚动时按需重新加载。

## 9. 隐私与安全

- 唯一的联网行为是更新检查和下载：访问 GitHub 的 Releases 页面与 `raw.githubusercontent.com`，User-Agent 为 `TinyPlayer/<版本>`，不带任何标识或使用数据。可在 设置 → 界面 关闭；隐私模式下不自动检查。
- 下载的更新包必须与发布的 `SHA256SUMS` 一致才会安装；macOS 还会做 `codesign --verify`。
- 媒体库密码只保存加盐的慢哈希，用于挡住界面入口，不加密视频或缩略图。
- 隐私模式：不写播放记录和播放次数，系统媒体控制不显示片名，重启后自动关闭。

## 10. 已知限制

- 平台：只有 Windows x64 和 macOS Apple 芯片安装包；没有 Intel Mac 和 Linux 安装包。macOS 版尚未公证。
- 程序被强制结束时，最多丢失最近 10 秒的进度。
- VR：不支持 VR 头显和鱼眼格式；3D 视频只显示左眼；全景模式下不显示字幕。
- 书签只支持本地文件，文件大小变了就不再匹配。
- 网络地址可以播放（命令行或拖入），但没有“打开网址”入口，也不生成进度条预览。
- 窗口置顶、画中画、睡眠定时、第二字幕、旋转、色彩和延迟只在本次运行有效。
- Windows 上有用户反映整机卡死，原因尚未确认，怀疑与 GPU 有关（硬件解码经 OpenGL 互通、画质增强或插帧在多屏下的负载）。排查方法见 [architecture.md §11](architecture.md#11-排错)。
