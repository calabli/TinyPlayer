# TinyPlayer

跨平台（Windows / macOS）本地视频播放器。Rust + egui（OpenGL）+ libmpv，目标是快、稳、占用小。

## 打包

| 平台 | 命令 | 产物 |
|---|---|---|
| Windows | `powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1` | `dist\TinyPlayer-<版本>-windows-x64.zip`（便携版，解压即用，约 48MB）；装了 [Inno Setup](https://jrsoftware.org/isinfo.php) 时还会生成 `-setup.exe` 安装程序（无需管理员权限） |
| macOS | `scripts/package-macos.sh`（需要 `brew install mpv dylibbundler` 和 Xcode 命令行工具） | `dist/TinyPlayer.app` 和 `dist/TinyPlayer-<版本>-macos-<架构>.dmg`（约 32MB，打开后把 TinyPlayer 拖到“应用程序”即可安装）；设置 `SIGN_IDENTITY`、`NOTARY_PROFILE` 可签名公证 |

安装包要求的最低 macOS 版本由打包时的依赖库决定，脚本会自动写入 `Info.plist`：用 Homebrew 的 libmpv 打包时，通常等于打包机器的系统版本。

macOS 脚本默认只做临时签名，在本机可直接运行。发给别人的话，对方首次打开时系统会拦截，要先打开一次，再到“系统设置 → 隐私与安全性”点“仍要打开”；用 Developer ID 签名并公证后分发就不会被拦截。安装包只支持打包机器的架构。脚本最后会逐个加载包内的库，有库加载失败或仍依赖 Homebrew 时直接报错。

推送到 `main` 时，GitHub Actions 会自动编译 Windows x64 和 macOS（Apple 芯片）安装包，可在 Actions 页面的构建记录里下载。推送 `v*` 标签时还会发布到 Releases。安装包都没有付费签名，首次打开时 Windows SmartScreen 或 macOS 可能会拦截。

分发前请阅读 [THIRD_PARTY.md](THIRD_PARTY.md) 中关于 libmpv 许可（GPL / LGPL）的说明。

## 构建与运行

```bash
cargo run --release -- "D:/path/to/video.mp4"
```

构建脚本会把 `third_party/mpv/<平台>/` 下的 libmpv 复制到可执行文件旁边：

| 平台 | 需要的文件 |
|---|---|
| Windows | `third_party/mpv/windows/libmpv-2.dll`（来自 [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake/releases) 的 `mpv-dev-x86_64` 包） |
| macOS | `third_party/mpv/macos/libmpv.2.dylib`（可用 `brew install mpv` 后从 Homebrew 目录复制，并一起打包依赖库） |

libmpv 体积较大，没有提交到 git。

## 性能

在 16 核 / NVIDIA 显卡的 Windows 机器上，用 release 版实测（1440P H.264，NVDEC 硬解）：

| 场景 | CPU | 内存（任务管理器「内存」列） |
|---|---|---|
| 启动到窗口出现 | — | 约 0.47 秒 |
| 空闲（空状态页） | 0% | 约 94 MB |
| 播放 1440P | 单核约 2–16%（整机 1% 以内） | 约 173 MB |
| 暂停 / 播放结束 | 0% | 约 138 MB |
| 400 个视频的媒体库，从头滚到尾 | — | 109 → 112 MB |

做过的优化：只在有新帧或输入时重绘；单实例先抢端口再连接（冷启动少约 300 ms）；中文字体用内存映射加载（约 −19 MB）；本地文件不强制预读缓存（`cache=auto`）；后台生成缩略图的 mpv 实例用完即释放（大媒体库约 −130 MB）；缩略图纹理最多保留 160 张，滚动时按需重新加载。

## 桌面集成

- **记住窗口**：退出时保存窗口位置、大小和是否最大化，下次启动恢复（全屏状态不保存）
- **单实例**：TinyPlayer 已在运行时，再打开视频（双击、拖到 exe 上、命令行）会交给已有窗口播放并把它切到前台，不会再开一个窗口。实现方式是本机回环端口通信，端口由数据目录推算，所以设置了不同 `TINYPLAYER_DATA_DIR` 的实例（测试、便携版）互不干扰
- **文件关联**（Windows 安装版）：所有支持的格式都能在“打开方式”和系统的默认应用设置里选 TinyPlayer，右键菜单还有“用 TinyPlayer 播放”（Windows 11 在“显示更多选项”里）。Windows 不允许程序自己设为默认播放器，要设默认请在“打开方式”里勾选“始终”。卸载时一并清除。便携版 zip 不做这些注册
- **打开方式**（macOS）：可以从访达双击或用“打开方式”选择 TinyPlayer，TinyPlayer 已在运行时交给已有窗口
- **图标**：`python scripts/make-icon.py` 只用标准库生成 `assets/` 下的图标；Windows 构建时嵌入 exe，窗口左上角也使用它；macOS 打包脚本会转成 `.icns`
- **媒体键**：键盘媒体键、macOS 控制中心、Windows 音量浮层可以播放、暂停、切换上一个/下一个，并显示当前标题和进度
- **阻止休眠**：播放视频时屏幕不熄灭，只播音频时系统不休眠但屏幕可以熄灭；暂停或播完后恢复
- **无边框播放**：播放时隐藏窗口标题栏，控件自动隐藏后只剩画面。按 H 或在快捷面板的“画面增强”里开关，设置会保存。拖动画面移动窗口，鼠标移到顶部后右上角有关闭按钮；回到媒体库或全屏时恢复标题栏
- **画中画**：无边框小窗置顶在屏幕右下角，拖动画面可移动窗口，退出后回到原位置和大小；全屏时需先退出全屏。窗口置顶和画中画只在本次运行有效
- **字幕避让**：控制栏显示时字幕自动上移到进度条上方，隐藏后回到底部

## 快捷设置面板

播放时点控制栏的设置按钮，在画面右下角弹出：

| 页 | 内容 |
|---|---|
| 字幕 | 字幕轨道切换（含关闭）、加载字幕文件、字幕大小、位置、字幕延迟 ±0.5 秒 |
| 字幕样式 | 第二字幕（双字幕）、字体、颜色、描边、阴影、覆盖 ASS 样式 |
| 声音 | 音轨切换、声道（立体声 / 左 / 右 / 混合）、音频延迟 ±0.1 秒、音量 ±5% / 静音、音量标准化 |
| 均衡器 | 10 段（31 Hz ~ 16 kHz，±12 dB），预设：关闭 / 低音 / 人声 / 高音 / 影院 |
| 画面 | 画面比例（原始 / 4:3 / 16:9 / 2.35:1 / 铺满窗口 / 21:9）、向左/向右旋转、水平镜像 / 垂直翻转、硬件加速、画质增强（去色带 + 更锐利的缩放，GPU 占用更高）、重置 |
| 画面增强 | 裁剪（去黑边 / 16:9 / 4:3 / 2.35:1 / 1:1）、缩放、HDR 色调映射、插帧 |
| 色彩 | 亮度、对比度、饱和度、伽马、色调（-100 ~ +100，靠近 0 时自动吸附）、重置 |

画面比例、硬件加速、画质增强、字幕大小、位置和样式、音量标准化、均衡器会保存；HDR 色调映射、插帧也会保存；第二字幕和声道只在本次运行有效，裁剪和缩放只对当前文件有效；旋转、翻转、色彩和延迟只在本次运行有效。翻转由 CPU 上的视频滤镜完成，开启时硬件解码自动切到回传模式（`auto-copy-safe`），占用略高，关闭后恢复。点面板外或按 Esc 关闭，「更多设置」打开完整设置窗口（也可按 Ctrl/⌘+,）。

## 界面

设置 → 界面 可以切换主题和语言，立即生效并保存：

- **主题**：深色、浅色、跟随系统。只影响媒体库、空状态页和设置窗口；控制栏、侧栏和快捷面板压在画面上，始终是深色
- **检查更新**：启动后最多每天访问一次 GitHub，发现新版本时在媒体库右下角提示，“查看”打开发布页，“跳过此版本”不再提示这个版本。不会自动下载或安装，也不发送使用数据；可在 设置 → 界面 关闭或手动检查，无痕模式下不自动检查。需要系统自带的 `curl`（macOS、Windows 10/11 都有）
- **语言**：中文、English。播放时的部分英文提示（如 `VOLUME 60%`）两种语言下相同

## 播放列表

- 打开单个文件时，自动把同一文件夹的其他媒体文件按**自然顺序**加入列表（「第2讲」排在「第10讲」前面），可在 设置 → 播放 中关闭。**先立即播放，同目录扫描在后台线程进行**，扫完再并入列表，不影响起播速度（实测 2 万个文件的文件夹也能立即开始播放）；扫描期间如果手动改了列表或打开了别的文件，结果会被丢弃
- 拖入或打开文件夹 = 播放整个文件夹
- 播完后：播下一个 / 列表循环 / 单个循环；随机播放保证每个文件播一次后才重复
- 侧栏**浮在画面上方，不会缩放视频**。打开方式：暂停后点画面右侧的 ‹，或控制栏的列表按钮，或按 L
- 侧栏内：点击播放、拖动排序、悬停出现 × 移除；鼠标在侧栏上时滚轮滚动列表（不调音量）

列表由程序自己管理（不用 mpv 内置播放列表），以便控制循环、随机、排序等规则。

## 画面增强

- **去黑边**：用一个无窗口的 libmpv 实例取视频 20% 处的约 1 秒画面检测黑边，不影响正在播放的画面；所取片段全黑或黑边不足 2% 时不裁剪
- **HDR 色调映射**：把 HDR 画面映射到显示器范围，非 HDR 视频不起作用
- **插帧**：混合相邻帧让运动更平滑，默认关闭。开启后界面按屏幕刷新率持续重绘，CPU/GPU 占用更高，也更费电。render API 不提供刷新率，所以程序每 2 秒读取 mpv 的测量值并吸附到最近的标准刷新率，窗口移到其他显示器后会自动跟上

## 音效

音量标准化自动拉近响亮和安静段落的差距，用的是 FFmpeg 的 `dynaudnorm`（RMS 模式）。它需要向后看约 1 秒音频，所以只在开启时有这部分处理延迟。均衡器提升某一段时，会先按最大提升量降低整体音量，防止削波，所以开启后整体可能变轻。

## 章节和书签

- **章节**：有章节的文件在进度条上显示刻度，悬停时显示章节名。上一章在章节开始 3 秒内跳到前一章，之后回到本章开头
- **书签**：Ctrl/⌘+B 在当前位置添加，进度条上用圆点标出，1 秒内不重复添加。书签和播放次数一样，清除播放记录时保留；无痕模式下不保存；只支持本地文件，文件大小变了就不再匹配
- 按 G 或点侧栏的 MARKS 标签，可按时间查看章节和书签，点击跳转，悬停书签出现 × 删除

## 进度条预览

鼠标悬停或拖动进度条时显示该位置的画面。后台用一个无窗口的 libmpv 实例取最近的关键帧，只处理最新的请求，每个文件最多缓存 24 张，空闲 20 秒后释放该实例。网络地址不生成预览。

设好 A-B 循环后，进度条上会用黄色标出循环区间；打开新文件时自动清除。

## 媒体库

没有播放时显示媒体库首页。点「+ 添加文件夹」后，后台会递归扫描文件夹，用一个无窗口的 libmpv 实例（`vo=image`）读取时长、分辨率，并截取 10% 处的画面作为缩略图（480 像素宽，约 0.2 秒一个）。每次启动会重新扫描，以发现新增或修改过的文件。

- 左侧导航：全部 / 继续观看 / 最近添加（7 天内）、标签筛选（可多选，同时满足）、按文件夹筛选；悬停文件夹出现 × 可从媒体库移除（不删除文件）
- 搜索：同时匹配标题、标签和路径，多个关键词用空格分隔；Ctrl/⌘+K 聚焦，Esc 清空
- 排序：最近添加 / 最近播放 / 名称（自然排序）/ 时长
- 卡片：缩略图、分辨率角标、时长、观看进度、播放次数、标签；点「+ 标签」添加，右键菜单可移除标签、在资源管理器/访达中显示、从媒体库移除
- 播放界面左上角「‹ 媒体库」返回首页
- **收藏夹**：悬停卡片点右上角星标，勾选要放入的收藏夹（可多个，可在弹窗里直接新建）；左侧 COLLECTIONS 点「+」新建，右键删除。播放时标题旁的星标或 Ctrl/⌘+D 快速收藏/取消（放入第一个收藏夹）。只有媒体库里的视频能收藏
- **最常播放**：按播放次数排名，前三名高亮；任意视图也可按「播放次数」排序
- **文件夹视图**：顶栏切换「媒体库 / 文件夹」，面包屑导航、↑ 返回上级；子文件夹显示为四宫格封面卡片（视频数、总时长、已看完数量），「播放全部」或右键文件夹卡片按自然顺序播放其中所有视频

搜索用 `LIKE` 而不是 FTS5：SQLite 的全文分词不切分中文，「王朝」搜不到「大明王朝」。几千条记录在内存里过滤也只需不到 1 毫秒。

缩略图保存在数据目录的 `thumbs/` 下。

## 播放记录

数据存在 SQLite：Windows 为 `%APPDATA%\TinyPlayer\tinyplayer.db`，macOS 为 `~/Library/Application Support/TinyPlayer/tinyplayer.db`。
开发测试时可以设置环境变量 `TINYPLAYER_DATA_DIR` 指向别的目录，避免写入真实记录。

| 规则 | 说明 |
|---|---|
| 文件识别 | 路径 + 文件大小；同名但内容换了的文件不会继承旧进度 |
| 何时保存 | 每播放 10 秒、暂停、播完、切换文件、正常退出时 |
| 防误删 | 实际观看不到 5 秒不写入，打开后马上关闭不会覆盖上次的进度 |
| 播放次数 | 实际观看 ≥ 30 秒或时长的 10%（取较小值）才 +1；30 分钟内重复打开只算一次；按真实时间计，倍速不影响 |
| 退出时清除 | 只清空进度和最近播放，**播放次数保留**；启动时也会再清一次，防止上次崩溃没清掉 |
| 无痕模式 | 本次运行不写入任何记录（包括播放次数），重启后自动关闭 |

已知限制：程序被强制结束时，最多丢失最近 10 秒的进度。

## 代码结构

```
src/
  main.rs     窗口配置、命令行参数
  app.rs      播放界面：视频层、底部控制栏、播放列表侧栏、OSD、空状态
  player.rs   播放状态与命令（基于 mpv 属性监听）
  history.rs  SQLite 存储：进度、播放次数、书签、设置
  library.rs  媒体库存储：文件夹、视频、标签
  library_ui.rs 媒体库首页
  scanner.rs  后台扫描与缩略图生成线程
  hover_thumbs.rs 进度条悬停预览（后台取帧与缓存）
  marks.rs    章节与书签的跳转规则
  view.rs     缩放平移、裁剪计算、刷新率吸附
  crop_detect.rs 后台检测黑边
  audio_fx.rs 音量标准化、均衡器、声道选择的滤镜生成
  ab_loop.rs  A-B 循环的取点规则
  media_keys.rs 系统媒体键与正在播放信息
  keep_awake.rs 播放时阻止系统休眠
  probe.rs    无窗口 libmpv：读时长/分辨率、截缩略图
  session.rs  当前文件的会话：何时保存、何时计数、是否续播
  playlist.rs 播放队列：同目录扫描、自然排序、循环与随机
  settings_panel.rs  完整设置窗口（播放 / 画面 / 字幕 / 播放记录 / 快捷键）
  quick_panel.rs     播放时的快捷设置面板（字幕 / 声音 / 画面 / 色彩）
  single_instance.rs 单实例：把后续打开的文件转交给已运行的窗口
  mac_open.rs 接收 macOS 访达打开文件的事件
  mpv.rs      libmpv 运行时加载的 FFI 封装 + OpenGL 渲染上下文
  video.rs    mpv 渲染目标（FBO → egui 纹理）
  icons.rs    矢量图标（不依赖图标字体或图片）
  theme.rs    配色、系统中文字体、浅色主题
  update.rs   检查新版本
  i18n.rs     界面语言：中文原文作键，`tr` / `tf` 取译文
  i18n_en.rs  英文翻译表
```

渲染流程：mpv 通过 render API 把画面画进 FBO 纹理，egui 把它当普通图片显示，控制栏和侧栏叠在上面。
只有 mpv 通知有新帧，或者有用户输入时才重绘，暂停时不占 CPU。
