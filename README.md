# TinyPlayer

跨平台（Windows / macOS）本地视频播放器。Rust + egui（OpenGL）+ libmpv，目标是快、稳、占用小。

## 打包

| 平台 | 命令 | 产物 |
|---|---|---|
| Windows | `powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1` | `dist\TinyPlayer-<版本>-windows-x64.zip`（便携版，解压即用，约 48MB） |
| macOS | `scripts/package-macos.sh`（需要 `brew install mpv dylibbundler`） | `dist/TinyPlayer.app` 和 `.dmg`；设置 `SIGN_IDENTITY`、`NOTARY_PROFILE` 可签名公证。**此脚本尚未在 Mac 上实际运行过** |

分发前请阅读 [THIRD_PARTY.md](THIRD_PARTY.md) 中关于 libmpv 许可（GPL / LGPL）的说明。

## 构建与运行

```bash
cargo run --release -- "D:/path/to/video.mp4"
```

构建脚本会把 `third_party/mpv/<平台>/` 下的 libmpv 复制到可执行文件旁边：

| 平台 | 需要的文件 |
|---|---|
| Windows | `third_party/mpv/windows/libmpv-2.dll`（来自 [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake/releases) 的 `mpv-dev-x86_64` 包） |
| macOS | `third_party/mpv/macos/libmpv.2.dylib`（可用 `brew install mpv` 后从 Homebrew 目录复制，并一起打包依赖库） |

libmpv 体积较大，没有提交到 git。

## 快捷设置面板

播放时点控制栏的设置按钮，在画面右下角弹出：

| 页 | 内容 |
|---|---|
| 字幕 | 字幕轨道切换（含关闭）、加载字幕文件、字幕大小、位置、字幕延迟 ±0.5 秒 |
| 声音 | 音轨切换、音频延迟 ±0.1 秒、音量 ±5% / 静音 |
| 画面 | 画面比例（原始 / 4:3 / 16:9 / 2.35:1 / 铺满窗口 / 21:9）、向左/向右旋转、水平镜像 / 垂直翻转、硬件加速、画质增强（去色带 + 更锐利的缩放，GPU 占用更高）、重置 |
| 色彩 | 亮度、对比度、饱和度、伽马、色调（-100 ~ +100，靠近 0 时自动吸附）、重置 |

画面比例、硬件加速、画质增强、字幕大小和位置会保存；旋转、翻转、色彩和延迟只在本次运行有效。点面板外或按 Esc 关闭，「更多设置」打开完整设置窗口（也可按 Ctrl/⌘+,）。

## 播放列表

- 打开单个文件时，自动把同一文件夹的其他媒体文件按**自然顺序**加入列表（「第2讲」排在「第10讲」前面），可在 设置 → 播放 中关闭。**先立即播放，同目录扫描在后台线程进行**，扫完再并入列表，不影响起播速度（实测 2 万个文件的文件夹也能立即开始播放）；扫描期间如果手动改了列表或打开了别的文件，结果会被丢弃
- 拖入或打开文件夹 = 播放整个文件夹
- 播完后：播下一个 / 列表循环 / 单个循环；随机播放保证每个文件播一次后才重复
- 侧栏**浮在画面上方，不会缩放视频**。打开方式：暂停后点画面右侧的 ‹，或控制栏的列表按钮，或按 L
- 侧栏内：点击播放、拖动排序、悬停出现 × 移除；鼠标在侧栏上时滚轮滚动列表（不调音量）

列表由程序自己管理（不用 mpv 内置播放列表），以便控制循环、随机、排序等规则。

## 媒体库

没有播放时显示媒体库首页。点「+ 添加文件夹」后，后台会递归扫描文件夹，用一个无窗口的 libmpv 实例（`vo=image`）读取时长、分辨率，并截取 10% 处的画面作为缩略图（480 像素宽，约 0.2 秒一个）。每次启动会重新扫描，以发现新增或修改过的文件。

- 左侧导航：全部 / 继续观看 / 最近添加（7 天内）、标签筛选（可多选，同时满足）、按文件夹筛选；悬停文件夹出现 × 可从媒体库移除（不删除文件）
- 搜索：同时匹配标题、标签和路径，多个关键词用空格分隔；Ctrl/⌘+K 聚焦，Esc 清空
- 排序：最近添加 / 最近播放 / 名称（自然排序）/ 时长
- 卡片：缩略图、分辨率角标、时长、观看进度、播放次数、标签；点「+ 标签」添加，右键菜单可移除标签、在资源管理器/访达中显示、从媒体库移除
- 播放界面左上角「‹ 媒体库」返回首页
- **收藏夹**：悬停卡片点右上角星标，勾选要放入的收藏夹（可多个，可在弹窗里直接新建）；左侧 COLLECTIONS 点「+」新建，右键删除。播放时标题旁的星标或 Ctrl/⌘+D 快速收藏/取消（放入第一个收藏夹）。只有媒体库里的视频能收藏
- **最常播放**：按播放次数排名，前三名高亮；任意视图也可按「播放次数」排序
- **文件夹视图**：顶栏切换「媒体库 / 文件夹」，面包屑导航、↑ 返回上级；子文件夹显示为四宫格封面卡片（视频数、总时长、已看完数量），「播放全部」或右键文件夹卡片按自然顺序播放其中所有视频

搜索用 `LIKE` 而不是 FTS5：SQLite 的全文分词不切分中文，「王朝」搜不到「大明王朝」。几千条记录在内存里过滤也只需不到 1 毫秒。

缩略图保存在数据目录的 `thumbs/` 下。

## 播放记录

数据存在 SQLite：Windows 为 `%APPDATA%\TinyPlayer\tinyplayer.db`，macOS 为 `~/Library/Application Support/TinyPlayer/tinyplayer.db`。
开发测试时可以设置环境变量 `TINYPLAYER_DATA_DIR` 指向别的目录，避免写入真实记录。

| 规则 | 说明 |
|---|---|
| 文件识别 | 路径 + 文件大小；同名但内容换了的文件不会继承旧进度 |
| 何时保存 | 每播放 10 秒、暂停、播完、切换文件、正常退出时 |
| 防误删 | 实际观看不到 5 秒不写入，打开后马上关闭不会覆盖上次的进度 |
| 播放次数 | 实际观看 ≥ 30 秒或时长的 10%（取较小值）才 +1；30 分钟内重复打开只算一次；按真实时间计，倍速不影响 |
| 退出时清除 | 只清空进度和最近播放，**播放次数保留**；启动时也会再清一次，防止上次崩溃没清掉 |
| 无痕模式 | 本次运行不写入任何记录（包括播放次数），重启后自动关闭 |

已知限制：程序被强制结束时，最多丢失最近 10 秒的进度。

## 代码结构

```
src/
  main.rs     窗口配置、命令行参数
  app.rs      播放界面：视频层、底部控制栏、播放列表侧栏、OSD、空状态
  player.rs   播放状态与命令（基于 mpv 属性监听）
  history.rs  SQLite 存储：进度、播放次数、设置
  library.rs  媒体库存储：文件夹、视频、标签
  library_ui.rs 媒体库首页
  scanner.rs  后台扫描与缩略图生成线程
  probe.rs    无窗口 libmpv：读时长/分辨率、截缩略图
  session.rs  当前文件的会话：何时保存、何时计数、是否续播
  playlist.rs 播放队列：同目录扫描、自然排序、循环与随机
  settings_panel.rs  完整设置窗口（播放 / 画面 / 字幕 / 播放记录 / 快捷键）
  quick_panel.rs     播放时的快捷设置面板（字幕 / 声音 / 画面 / 色彩）
  mpv.rs      libmpv 运行时加载的 FFI 封装 + OpenGL 渲染上下文
  video.rs    mpv 渲染目标（FBO → egui 纹理）
  icons.rs    矢量图标（不依赖图标字体或图片）
  theme.rs    配色、系统中文字体
```

渲染流程：mpv 通过 render API 把画面画进 FBO 纹理，egui 把它当普通图片显示，控制栏和侧栏叠在上面。
只有 mpv 通知有新帧，或者有用户输入时才重绘，暂停时不占 CPU。
